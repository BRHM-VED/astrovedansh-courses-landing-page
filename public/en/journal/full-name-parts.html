Why first-name and full-name calculations differ

AstroVedansh Journal·156 words

Updated: 17 October 2026

Define which name is being calculated before comparing results. A first name, full name and public name may contain different letters. Including a surname in one calculation but excluding it in another creates an uneven comparison. State the scope instead of presenting all totals as interchangeable.

Using the declared repeating table: ANITA=18→9; RAO=16→7; ANITA RAO=34→7.

First name, full name and commonly used name are different inputs. Label which one you are calculating each time. If one tool uses a full name while another uses only the first, resolve that difference before comparing totals. Spaces receive no numeric value in the alphabet table used here. If another method supplies additional conventions, read them explicitly. Understanding a name number therefore involves more than addition. It also requires a clear definition of what was included, what was excluded, and which letter mapping was applied to the chosen spelling.

Different first-name and full-name totals need not indicate an addition error.
